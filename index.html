    LumiHome

    Smart Lighting Dashboard · v1.0

    Website Smart Home berbasis IoT yang dapat digunakan untuk mengontrol lampu rumah dari jarak jauh. website ini Mendukung tiga mode koneksi: Demo (tanpa perangkat), Blynk Cloud (jarak jauh), dan ESP langsung (satu jaringan WiFi).

    Fitur Utama

    • Kontrol on/off 4 lampu + status real-time
    • Timer per lampu & timer universal
    • Scene cepat: tidur, keluar rumah, semua on/off
    • Multi-mode: Demo · Blynk Cloud · ESP langsung
    • Activity log, dark/light theme, responsif

    Dibangun Dengan

    HTML5 CSS3 JavaScript Blynk Cloud ESP8266 / ESP32
